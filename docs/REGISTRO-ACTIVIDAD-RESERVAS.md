# Registro interno: gestión de reservas

| Campo | Contenido |
| --- | --- |
| Responsable | Cada restaurante contratado |
| Actividad | Gestión de solicitudes, confirmaciones, cambios y cancelaciones |
| Personas | Clientes y acompañantes identificados por la persona que reserva |
| Datos | Nombre, contacto, fecha, hora, personas, estado y observaciones no médicas |
| Finalidad | Gestionar la reserva y las comunicaciones relacionadas |
| Base | Solicitud previa y condiciones aceptadas |
| Destinatarios | Proveedores tecnológicos por cuenta del restaurante y autoridades cuando sea obligatorio |
| Conservación | La definida por cada restaurante en el panel |
| Seguridad | Acceso autenticado, separación por restaurante, RLS, HTTPS, registro de aceptación y copias del proveedor |
| Transferencias | Revisar según la ubicación y garantías de cada proveedor contratado |

Revisar este registro cuando cambien los proveedores, los datos solicitados, el plazo de conservación o el uso de la información.
