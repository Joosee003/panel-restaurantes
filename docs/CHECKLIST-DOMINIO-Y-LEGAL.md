# Checklist para publicar el dominio de un restaurante

## Datos del restaurante

- [ ] Titular o razón social
- [ ] NIF/CIF
- [ ] Domicilio legal
- [ ] Email legal y de privacidad
- [ ] Datos registrales, si corresponden
- [ ] Plazo de conservación de reservas revisado
- [ ] Horarios, capacidad y cancelación revisados

## Dominio

- [ ] Guardar el dominio sin `https://` en Ajustes → Web y reservas
- [ ] Añadir el dominio y `www` al proyecto de Vercel
- [ ] Configurar los registros DNS indicados por Vercel
- [ ] Comprobar HTTPS
- [ ] Comprobar la portada, carta, formulario y las cuatro páginas legales
- [ ] Comprobar `robots.txt` y `sitemap.xml`

## Reservas

- [ ] Hacer una reserva de prueba
- [ ] Confirmar que aparece en el panel correcto
- [ ] Confirmar que respeta horarios, cierres y capacidad
- [ ] Confirmar que el enlace de cambio o cancelación funciona
- [ ] Eliminar la reserva de prueba

## Cookies

- [ ] Confirmar que no hay analítica, publicidad ni scripts opcionales
- [ ] Si se añade alguno, instalar antes un panel de elección y actualizar la política
